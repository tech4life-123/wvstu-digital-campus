Step 5 — Program selection Locked after first save

WVSTU runs two terms per year — Semester I (begins around August 26) and Semester II — not Fall/Winter. Once a program is selected and saved, it cannot be changed by the student; a change before Sophomore standing must be requested through the Registrar/Admissions Office.

Step 6 — Documents PDF only

Upload scanned copies of your WASSCE/LSHCE results and supporting documents. Only PDF files are accepted — the system will reject any other format. Each upload must be approved by Admissions before your "Documents received" step is checked off below.

Student accounts Real Supabase Auth — passwords never touch this app

Student login now runs on Supabase Auth directly, so passwords are hashed and stored by Supabase — not by this app, and not visible to anyone here, admin included. A student can change their own password from Profile → Change password. Resetting a forgotten password for someone else requires Supabase's admin API with a service-role key, which only belongs on a secure server — never in this browser page.
